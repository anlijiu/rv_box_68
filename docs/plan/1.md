**源名称 → FreeCAD 名称映射规则**：去除通用后缀（Assembly/System），用下划线连接，压缩常见缩写。不逐字保留源显示名。

| 源名称 | FreeCAD Label | 说明 |
|--------|--------------|------|
| Cargo Box Assembly | CargoBox | 压缩 |
| Exterior Accessories Assembly | Exterior_Accessories | 保留语义 |
| Fuel System Assembly | Fuel_System | 去 Assembly |
| Battery Management System | BMS | 常见缩写 |
| DC Distribution Panel | DC_Distribution | 精简 |
| Roof Air Conditioner | Roof_AC | 缩写 |

## 核心概念映射

| 业务概念 | kind 值 | FreeCAD 类型 | 说明 |
|---------|---------|-------------|------|
| **总成 (Assembly)** | `"assembly"` | `App::Part` | 容器，含子 assembly 或 body |
| **零件 (Part)** | `"body"` | `Part::Box` | 叶子节点，占位几何体。**注意：kind="body" 是业务语义，不是 FreeCAD 的 PartDesign::Body** |

> **为什么用 Part::Box 而不是 PartDesign::Body？**
> PartDesign::Body 的形状由其内部 PartDesign 特征（AdditiveBox / Sketch + Pad）计算得到，
> `body.Shape = box` 不是正确 API。骨架阶段用 `Part::Box` 作占位几何最简单可靠。后续细化时
> 再替换为 PartDesign::Body + 特征。

## 树数据校验

> **注意**：以下为说明用摘录，执行时以 Step 2 完整脚本为准。

在执行创建之前校验 TREE 数据完整性：

```python
def validate_tree(tree, path="root"):
    """校验树数据的完整性和一致性"""
    name, label, kind, children = tree

    # 1. kind 必须是 assembly 或 body
    assert kind in ("assembly", "body"), \
        f"{path}: kind must be 'assembly' or 'body', got '{kind}'"

    # 2. assembly 的 children 必须是 list
    # 3. body 的 children 必须是 None
    if kind == "assembly":
        assert isinstance(children, list), \
            f"{path}: assembly '{name}' children must be a list"
    else:
        assert children is None, \
            f"{path}: body '{name}' children must be None, got {type(children).__name__}"

    # 4. 检查同一父节点下 name 不重复
    if children:
        names = [c[0] for c in children]
        dupes = set(n for n in names if names.count(n) > 1)
        assert not dupes, f"{path}: duplicate child names: {dupes}"

        for child in children:
            validate_tree(child, f"{path}/{child[0]}")

validate_tree(TREE)
print("TREE validation OK")
```

## 自动统计（由 TREE 数据计算）

```python
def count_nodes(tree):
    """从树数据自动统计 assembly 和 body 数量"""
    _, _, kind, children = tree
    ac, bc = (1, 0) if kind == "assembly" else (0, 1)
    if children:
        for child in children:
            ca, cb = count_nodes(child)
            ac += ca; bc += cb
    return ac, bc

assembly_count, body_count = count_nodes(TREE)
print(f"Expected: {assembly_count} assemblies, {body_count} bodies, {assembly_count + body_count} total")
```

SUBSYSTEM_SPACING_X = 60   # 一级子系统沿 X 轴间距
BOX_SPACING_Y = 16          # 同级 body 沿 Y 轴间距
DEPTH_SPACING_Z = 16        # 子层级沿 Z 轴偏移
BOX_SIZE = 10               # 占位方块边长

def set_color(obj, color):
    if hasattr(obj, 'ViewObject') and obj.ViewObject:
        obj.ViewObject.ShapeColor = (*color, 1.0)

# ============================================================
# 5. 递归创建装配树（带 Placement 网格布局）
# ============================================================
def make_obj_name(prefix, name, kind):
    suffix = "Asm" if kind == "assembly" else "Box"
    return f"{prefix}_{name}_{suffix}"

def create_tree(doc, parent_obj, nodes, *, depth, subsystem_color):
    """递归创建装配树。
    - depth: 层级深度（控制 Z 偏移）
    - 每个节点在局部坐标中 Y 方向排列，避免重叠
    （X 偏移由一级子系统 Placement 统一设置，子节点不再叠加）
    """
    count = len(nodes)
    for i, (name, label, kind, children) in enumerate(nodes):
        obj_name = make_obj_name(parent_obj.Name, name, kind)

        # Y 偏移：同级节点居中排列
        y_offset = (i - (count - 1) / 2.0) * BOX_SPACING_Y
        # Z 偏移：子层级向下
        z_offset = -depth * DEPTH_SPACING_Z

        if kind == "assembly":
            obj = doc.addObject("App::Part", obj_name)
            obj.Label = label
            # 只使用局部坐标：父级已提供 X 偏移，子节点不再叠加
            obj.Placement.Base = App.Vector(0, y_offset, z_offset)
            parent_obj.addObject(obj)
            set_color(obj, subsystem_color)
            if children:
                create_tree(doc, obj, children,
                            depth=depth + 1,
                            subsystem_color=subsystem_color)
        else:
            # Part::Box 占位几何体
            obj = doc.addObject("Part::Box", obj_name)
            obj.Label = label
            obj.Height = BOX_SIZE
            obj.Width = BOX_SIZE
            obj.Length = BOX_SIZE
            # 相对于父 assembly 的局部位置
            obj.Placement.Base = App.Vector(0, y_offset, z_offset)
            parent_obj.addObject(obj)
            set_color(obj, subsystem_color)

def count_nodes(tree):
    _, _, kind, children = tree
    ac, bc = (1, 0) if kind == "assembly" else (0, 1)
    if children:
        for child in children:
            ca, cb = count_nodes(child)
            ac += ca; bc += cb
    return ac, bc

def count_created(obj):
    """从 FreeCAD 对象树递归统计（不依赖 doc.Objects 全量）"""
    ac = 1 if obj.TypeId == "App::Part" else 0
    bc = 1 if obj.TypeId == "Part::Box" else 0
    if hasattr(obj, "Group"):
        for child in obj.Group:
            ca, cb = count_created(child)
            ac += ca; bc += cb
    return ac, bc

expected_ac, expected_bc = count_nodes(TREE)
